# Skills

Three skills written on 2026-10-15 from the VELOMNA adoption, for Claude sessions (Code and Cowork) working on ZeroOrigine.

| Skill | Use it when |
|---|---|
| zo-adopt-product | adopting a founder-built product into the ecosystem: schema, API door, cron, repo, hosting, auth, beacon, registry, proof |
| zo-robustness-drills | proving a guard, brake, trigger, cron or edge function holds, with ok / fail / unknown verdicts and rollback drills |
| velomna-engine | any change to VELOMNA: constants, routes, laws, deploy and verify |

Each folder carries `evals/evals.json` (test prompts and assertions) and the iteration-1 benchmark (with skill vs without, same model, same prompts). The canonical copies live in the founder's Claude account; these are the repo mirrors.
